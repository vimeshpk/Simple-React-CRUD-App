# ⚛️ Simple React CRUD App

A **Simple React CRUD Application** built to demonstrate how to **Create, Read, Update, and Delete** user data efficiently using React.
This project is great for beginners who want to understand React fundamentals and component-based architecture.

---

## 🚀 Features

* ➕ **Create** new records
* 👀 **Read** and display data dynamically
* ✏️ **Update** existing entries
* ❌ **Delete** unwanted records
* ⚙️ Built with **React Hooks (useState, useEffect)**
* 🎨 Responsive and clean UI

---

## 🛠️ Tech Stack

* ⚛️ **React** – Frontend library
* 🧩 **React Router** – For navigation
* 💾 **LocalStorage / Mock API** – For data persistence
* 💅 **CSS / Tailwind / Bootstrap** – Styling (customize as per your setup)

## ⚙️ Setup and Run

### 1️⃣ Clone the repository

```bash
git clone https://github.com/yourusername/simple-react-crud-app.git
```

### 2️⃣ Move into the project folder

```bash
cd simple-react-crud-app
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Start the development server

```bash
npm start
```

App will be available at 👉 **[http://localhost:3000](http://localhost:3000)**

---

## 🧩 Example CRUD Flow

1. Click **“Add User”** to create a new entry.
2. View all users in the **User List**.
3. Use **“Edit”** to update details.
4. Use **“Delete”** to remove an entry.
